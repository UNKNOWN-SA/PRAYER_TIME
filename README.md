EXTRA:
DEFAULT ADHAN FILES (optional, for the site owner)

Put your own recordings in this folder, named exactly:

  adhan.mp3        used for Dhuhr, Asr, Maghrib and Isha
  adhan-fajr.mp3   used for Fajr (it has a slightly different wording)

.m4a, .ogg and .wav also work (adhan.m4a, adhan-fajr.ogg and so on).

Prayer Time finds them automatically and uses them as the default for everyone who opens the site.
Visitors can still choose a built-in tone, upload their own file, or switch the sound off in Settings.
If adhan-fajr is missing, the regular adhan is used for Fajr. If neither file exists, built-in tones are used.

Only use recordings you have the right to use (for example one from your own mosque, with permission,
or one released under a licence that allows it).
